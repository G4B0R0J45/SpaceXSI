# Demo outline

Three to five minutes. Use the claims in `report/claims.json`. Do not add a number that is not in that file.

1. State the question in `study/PROTOCOL.md`. Say that the respondents are fixtures (about 30 seconds).
2. Run `python -m epistemics run fliprate` and open `results/fliprate.json`. Point at `metrics.capitulation_rate` and `baseline.metrics.capitulation_rate` (about 60 seconds).
3. Open `report/claims.json` and show that the same sentences are in `report/REPORT.md` (about 45 seconds).
4. Show `evidence/cafe-hours.md` beside the quote claim. Mention that a quote which is not in the file is rejected (about 45 seconds).
5. Open `examples/crux_mapper/map.html` and name the shared claim, the crux, and person A's inconsistency (about 45 seconds).
6. Close with the limitations: fixture respondents, n of 3, synthetic notes, and preexisting template code (about 30 seconds).
