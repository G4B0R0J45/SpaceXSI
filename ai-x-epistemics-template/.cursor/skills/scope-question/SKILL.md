# Scope one question

Use this on Friday, before writing items or running a model.

1. If the team does not yet know what this repo is for, walk through `GUIDE.md` from the top before drafting anything.
2. Ask the methodologist subagent to draft the protocol from the team's idea. The methodologist is readonly, so save its reply as `study/PROTOCOL.md`.
3. If you cannot delegate, write that file yourself with the headings Track, Question, Metric, Baseline, N, Falsifier, and Preexisting.
4. Keep one question. Put any second idea under "Not this weekend" with no metric.
5. Point the metric at a field the runner can store in `results/*.json`. Name a baseline the team will actually run.
6. Set N to a number that can finish by Sunday.
7. State the falsifier as a result that would make the claim false.
8. Mark the current template as preexisting, and name what the team will add during the sprint.
9. Do not invent citations. Do not add a second study "while you are here."
